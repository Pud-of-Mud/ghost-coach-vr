# Ghost Coach

**Minimum Product**

- Full body input of the user  
- Record mocap of a trainer   
- Display ghost of trainer overlapping the user  
- Display report of each limb and the user’s performance 

## Ideal Product

- Use haptic stimuli to give instant feedback as the user performs the action  
- Face structure recording

## Add spice  
### During Execution

- Mirror ghost   
- Colored live feedback of ghost   
- 3rd person camera 

### Post-Execution Feedback

- AI feedback on form   
- Overlay of both coach and user’s performance afterward

## Demonstration examples

- Running form  
- Gym/ Lifting form   
- Martial Arts  
- Runway  
- Poker Face
  
## Unity Version
Unity 6.3 LTS (6000.3.26f1)
